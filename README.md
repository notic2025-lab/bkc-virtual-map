# GFO 北館1F バーチャル3Dマップ 🏙️

グランフロント大阪 北館1F（https://www.gfo-sc.jp/information/floor/north/1f ）の
フロアマップを、探索して楽しいバーチャル3Dワールドとして再構築したWebアプリ。

## 起動方法

```bash
cd gfo_map
python3 -m http.server 8931
# → http://localhost:8931 をブラウザで開く
```

ビルド不要・依存ゼロ（Three.js は `vendor/` に同梱、CDN不要）。

## 機能

- **3Dバーチャルマップ** — 北館1Fの全14ショップ + InterContinental・オフィス棟・並木・せせらぎ・ナレッジプラザを立体表現。カテゴリ色分け（公式フロアマップ準拠）
- **ショップ情報** — 建物やラベルをクリック → ロゴ・カテゴリ・紹介文・公式ページへのリンクを表示。「☰ ショップ」から検索・カテゴリフィルタも
- **経路案内 (A→B)** — 出発地と目的地を選ぶと、通路グラフ上を A* 探索して光るルート＋動く矢印で表示。距離・徒歩時間の目安つき
- **🚶 お散歩モード** — アバターが経路を実際に歩き、追従カメラで移動体験
- **📱 ARナビ** — 経路表示後に「ARナビ」→ カメラ映像の上に進行方向のシェブロン矢印をオーバーレイ（デバイスのコンパスに追従）。カメラ非対応環境ではシミュレーション表示にフォールバック
- **🌙 昼/夜モード** — 夜はお店が発光

## スマホで使う場合（AR含む）

カメラ・コンパスは HTTPS または localhost が必要。同一LANのスマホから試すなら:

```bash
npx serve .   # や ngrok / cloudflared などでHTTPS化
```

iPhone は初回にコンパス利用の許可ダイアログが出ます。

## データについて

ショップ名・カテゴリ・紹介文・ピン座標は公式サイトのフロアマップデータ
（2026-07 時点）から取得。`js/data.js` に集約してあるので、店舗の入れ替えが
あればこのファイルだけ更新すれば反映されます。

## 構成

```
index.html      … UIレイアウト
css/style.css   … デザイン（グラスモーフィズムUI）
js/data.js      … ショップ / 施設 / 通路グラフ データ
js/app.js       … 3Dシーン・経路探索・お散歩モード・UI
js/ar.js        … ARナビ（カメラ + コンパス + Three.jsオーバーレイ）
vendor/         … Three.js 同梱
assets/         … 公式フロアマップ画像（参照用）
```
